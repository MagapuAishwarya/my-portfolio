# Personal Developer Portfolio

A personal portfolio website built with React and Vite with the help of AI coding tools. It showcases my introduction, technical skills, projects, education, resume, and contact information.

## About the Project

This portfolio is designed to present my technical background and development journey in a clean, modern, and responsive layout. It provides visitors with an overview of my skills, projects, and professional interests.

AI tools were used to assist with the initial project setup, component development, styling, and code improvements. I reviewed and customized the code to suit my portfolio.

## Features

- **Personal Introduction** - A brief introduction and professional profile.
- **Technical Skills** - Skills organized into categories.
- **Projects** - Project descriptions, technologies, and repository or demo links when available.
- **Education** - Academic qualifications and achievements.
- **Resume Download** - Access to my resume.
- **Contact Section** - Links to my email, LinkedIn, and GitHub.
- **Responsive Design** - Layout designed for desktop and mobile screens.
- **Interactive Navigation** - Section highlighting and a mobile navigation menu.

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm before running the project.

### Installation

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal and install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal, usually `http://localhost:5173/`.

## Project Structure

- `public/` - Public assets and resume
- `src/components/` - Reusable React components
- `src/data/` - Portfolio content and project details
- `src/App.jsx` - Main application layout
- `src/App.css` - Application styles
- `src/index.css` - Global styles
- `src/main.jsx` - React entry point
- `index.html` - HTML page
- `package.json` - Project dependencies and scripts
- `vite.config.js` - Vite configuration

## Customization

Update `src/data/content.js` to edit your personal information, skills, projects, education, contact links, and resume path.

You can update the component files and CSS files to customize the content, layout, and appearance.

## Build for Production

To create an optimized production build, run:

```bash
npm run build
```

To check the code with ESLint, run:

```bash
npm run lint
```
